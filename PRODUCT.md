## 5. Architectural Constraints
- **Framework:** Astro 5 (Static Site Generation / JAMstack for zero cost, maximum speed, and unbreakable uptime).
- **Styling:** Tailwind CSS v4.
- **Interactivity:** React 19 Islands (used selectively for high-value interactive widgets like the Project Calculator, Navbar, and Portfolio Tabs).
- **Hosting:** Vercel Global Edge Network with custom domain `zagdigitalid.com`.
- **Database Dependency:** Intentionally zero-database for the company profile to eliminate hosting fees, maintenance overhead, and vulnerability vectors.
